# Taller Práctico de Alto Nivel: Programación Funcional en Python

## Autor

**Luis Crespin**

## Descripción

Este repositorio contiene la solución del Taller Práctico de Alto Nivel de Programación Funcional en Python.

El taller permite aplicar diferentes conceptos de programación funcional mediante ejercicios prácticos utilizando funciones de orden superior (HOFs), closures, funciones lambda y composición de funciones.

## Objetivo

Aplicar técnicas de programación funcional en Python para desarrollar soluciones mediante funciones de orden superior, closures, lambdas y composición de funciones.

## Contenido

El taller está compuesto por 20 ejercicios organizados en cuatro niveles.

### Nivel 1: Closures con inyección de comportamiento

1. Generador de Formateadores con Transformación
2. Multiplicador Paramétrico con Mapeo
3. Calculador de Descuentos con Regla Dinámica
4. Generador de Seriales / Nombres Únicos
5. Conversor de Divisas con Margen

### Nivel 2: Estado encapsulado avanzado

6. Contador Ponderado
7. Acumulador con Filtro de Aceptación
8. Promediador con Eliminación de Valores Extremos
9. Limitador de Tasa Inteligente
10. Interruptor Múltiple

### Nivel 3: HOFs complejas

11. Pipeline de Mapeo y Filtrado Combinado
12. Reductor / Agrupador Personalizado
13. Ejecutor Repetitivo con Estado Accesible
14. Compositor de Cadenas de Operaciones
15. Decorador / HOF de Profiling y Auditoría

### Nivel 4: Patrones avanzados

16. Validador Compuesto de Reglas de Negocio
17. Caché con Tamaño Máximo
18. Motor de Pipeline Secuencial
19. Sistema Pub/Sub
20. Mini-Query Engine sobre Listas de Objetos

## Tecnologías utilizadas

* Python 3
* Funciones Lambda
* Higher-Order Functions (HOFs)
* Closures
* map()
* filter()
* all()
* nonlocal
* Composición de funciones

## Ejecución

Para ejecutar el programa se necesita tener instalado Python 3.

Ejecutar el archivo con:

python taller_funcional.py

El programa contiene pruebas mediante print() para verificar el funcionamiento de cada uno de los 20 ejercicios.
